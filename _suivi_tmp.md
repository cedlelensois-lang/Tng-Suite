## Propositions de l'audit 2.17.1 (non faites, à arbitrer par Cédric)
- Licence : mPDF est GPL-2.0-only alors que le plugin dit « GPLv2 or later » : passer l'en-tête en `GPL-2.0-only` (ou garder en l'expliquant) pour éviter toute contradiction.
- Dépôt de mises à jour : `TNGSUITE_GITHUB_REPO` pointe sur `cedlelensois-lang/tng-suite` (casse différente du dépôt `Tng-Suite`, GitHub redirige) : harmoniser. Le vérificateur GitHub serait à retirer pour une publication sur WordPress.org.
- Heatmap : l'API REST publique `tng-heatmap/v1/data` ne renvoie que des données agrégées (mêmes que la page) ; ajouter une limite de débit ou un cache de réponse côté serveur si le site est très visité.
- Ajouter un test automatique minimal (PHPUnit ou script `tools/`) qui compare les options écrites par le plugin (`update_option`/`register_setting`) à la liste de `uninstall.php`, pour éviter l'oubli d'options.
- Activer dans GitHub : « Private vulnerability reporting » (Settings > Code security) pour que le lien de `SECURITY.md` fonctionne.
- Pages en cache (extension de cache) : les appels AJAX publics de la fiche et de l'éventail utilisent un nonce ; avec un cache de page très long le nonce peut expirer (message d'erreur côté visiteur) : à surveiller, ou documenter l'exclusion de ces pages du cache.
