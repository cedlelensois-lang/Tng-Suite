# Fiche & listes de documents

Listes d’ascendants et de descendants et fiche individuelle, en PDF, Excel ou Word. Deux sections : Générer des documents et Réglages. Langues : français, anglais, catalan, espagnol.

## Dans l’administration

![Fiche & listes de documents](../images/individual%20sheet.png)

## Shortcodes

```
[tng_listes]
```

## Utilisation

1. Section « Générer des documents » : choisissez le type, la personne de départ et le nombre de générations, déployez « Champs affichés », puis Créer le document.
2. Section Réglages : champs affichés par défaut, langue pour le site public, accès réservé aux connectés.
3. Pour les visiteurs, collez [tng_listes] dans une page.

## Résultat sur le site

![Fiche & listes de documents](../images/Exemple%20individual%20sheet.png)

## Remarques

- Dans l’administration, la langue suit Général (français ou anglais), sauf catalan/espagnol choisis dans les réglages.
