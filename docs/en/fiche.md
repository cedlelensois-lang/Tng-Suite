# Individual sheet & document lists

Ancestor and descendant lists and an individual sheet, as PDF, Excel or Word. Two sections: Generate documents and Settings. Languages: French, English, Catalan, Spanish.

## In the admin

![Individual sheet & document lists](../images/individual%20sheet.png)

## Shortcodes

```
[tng_listes]
```

## How to use

1. “Generate documents” section: choose the type, starting person and generations, open “Fields shown”, then Create the document.
2. Settings section: default fields, language for the public site, login-only access.
3. For visitors, paste [tng_listes] into a page.

## Result on the site

![Individual sheet & document lists](../images/Exemple%20individual%20sheet.png)

## Notes

- In the admin, the language follows General (French or English), unless Catalan/Spanish is set in the settings.
