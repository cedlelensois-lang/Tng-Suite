# Record link button

A button that links to a person’s page in TNG.

## In the admin

![Record link button](../images/record%20link.png)

## Shortcodes

```
[tng_link id="I1" text="View record"]
```

## How to use

1. Set the button style (text, colours) on the module page.
2. Paste the shortcode with the person’s id; tree sets the tree if needed, text changes the label.
